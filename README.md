# Customer Segmentation using K-Means Clustering

This project is part of my **Machine Learning Internship at Prodigy InfoTech (Task-02)**.

## 📌 Objective

Build a K-Means clustering model to group retail store customers based on their **Annual Income** and **Spending Score**.

## 🛠️ Technologies Used

- Python

- Pandas

- NumPy

- Matplotlib

- Seaborn

- Scikit-learn

## 📂 Dataset

- Mall Customers Dataset

- Features Used:

  - Annual Income

  - Spending Score

## 📊 Workflow

- Load and explore the dataset

- Visualize customer data

- Apply the Elbow Method to find the optimal number of clusters

- Train the K-Means model

- Visualize customer clusters

- Analyze customer segments

## 📈 Results

Successfully segmented customers into different groups based on purchasing behavior, helping identify valuable customer categories for targeted marketing.
